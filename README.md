# CSE437: Data Science — Coding with Real-World Data

This project implements an end-to-end data science and machine learning pipeline using real-world biological data. Aligned with our research focus in bioinformatics, the objective is to classify breast tumor biopsy samples as either **malignant** or **benign** using digitized measurements of cell nuclei.

Beyond model building, this project covers the complete data science lifecycle required for the course:
- **Data Cleaning & Preprocessing:** Handling missing values, formatting features, and scaling.
- **Exploratory Data Analysis (EDA):** Visualizing feature distributions and relationships.
- **Hypothesis Testing:** Statistical evaluation of feature significance.
- **Dimensionality Reduction & Feature Engineering:** Applying techniques like PCA to improve model performance and efficiency.
- **Model Evaluation & Comparison:** Benchmarking multiple machine learning algorithms against one another.

---

## 📊 Dataset

* **Name:** Breast Cancer Wisconsin (Diagnostic) Data Set
* **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data)
